## Caveats (always)

A kill proves the suite noticed *this* change, not that it tests the right thing -- and **a clean sweep is evidence about the mutations tried, not proof of suite completeness.** Not covered here and deliberately left to the release checklist: what `SubagentStart` actually carries on a live box (subscriptions load at session start, so this session cannot observe it; the handler tolerates any shape and the debug log records the payload keys), and a deliberately failing tool call in a live session.
