## Caveats (always)

A kill proves the suite noticed *this* change, not that it tests the right thing -- and **a clean sweep is evidence about the mutations tried, not proof of suite completeness.** Not covered here and left to the release checklist: reading a real two-agent session with the mode on (a judgment about whether the short ids make the interleaved file readable), and the prefix search from a label back to the agent's transcript on a live box. The snapshot suite proved the default byte-identical (the synthetic session has no untyped agent, so the one intended default change -- `untyped/<8>` -- is pinned by `test_untyped_agent_bucketing.py` instead).
